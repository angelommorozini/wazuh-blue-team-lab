## Overview

This project demonstrates the deployment and configuration of a Blue Team detection lab using:

- Wazuh SIEM
- Sysmon
- Atomic Red Team
- MITRE ATT&CK Framework
- Windows 10 Endpoint Monitoring
- Ubuntu Server

The objective was to simulate adversary techniques using Atomic Red Team and validate custom detections created in Wazuh.

---

## Lab Architecture

```text
Windows 10 Endpoint
        │
        ▼
      Sysmon
        │
        ▼
   Wazuh Agent
        │
        ▼
   Wazuh Manager
   (Dockerized)
        │
        ▼
  Wazuh Dashboard
```
